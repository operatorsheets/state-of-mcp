The tool surface

8,629 tools across a random sample of 476 live servers (≈194,260+ ecosystem-wide). Only 18% declare an output contract — the rest return whatever they return. 46% of servers expose at least one tool pair an agent could plausibly confuse.

Contracts drift, and it clusters

4.4% of servers changed a tool contract within 36 hours; only 3 more in the next 36. Drift is not a steady rate — it is a small set of servers that never stop moving, plus a frozen majority. A server can be perfectly up and no longer do what your agent learned it does.

Method: every active remote entry in registry.modelcontextprotocol.io, deduplicated by URL, sent one anonymous JSON-RPC initialize (transport-aware; SSE handled).
